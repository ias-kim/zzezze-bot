# ADR 0007: 야추는 "야추겜 ㄱㄱ"로 따로 부르고, 음식 얘기는 약속 잡기로 바꾼다

## 상태

승인됨 (2026-11-09, 사용자 결정). 설계 문서의 "치킨 → [🎲 야추로 정하기]" 흐름을 대체한다.

## 맥락

처음 설계는 "치킨 시킬까?"가 나오면 주사위로 치킨값 담당을 정하는 것이었다. 사용자는 두 기능을 나누길 원했다. 야추는 하고 싶을 때 직접 부르는 게임이고, 음식 얘기가 나오면 필요한 건 "그래서 약속 언제 잡을래?"다.

## 결정

- **야추**: "야추겜 ㄱㄱ", "야추 ㄱ", "야추 한판" 같은 말에 바로 참가 모집 판을 올린다. 말한 사람은 자동 참가한다. 직접 부른 것이라 쿨다운과 `[🔕 오늘 그만]`이 없다. 규칙(60초 모집, 최저점 꼴찌, 동점 재굴림 3라운드 후 제비뽑기)은 그대로다. 벌칙은 친구들끼리 정하고, 봇은 꼴찌만 알려 준다.
- **음식**: 치킨·곱창·양꼬치 등(`features.Foods`) 얘기가 나오면 "약속 언제 잡을래요?"와 함께 `[⏰ 시간 투표] [🔕 오늘 그만]`을 띄운다. 투표 제목에 음식 이름이 들어간다("곱창 언제 먹으러 감?").
- 코드 이름: `yacht.Chicken` → `yacht.Quick`, `voice.Chicken*` → `voice.Yacht*`. 버튼 custom_id는 `yacht:join`, `nudge:poll[:음식]`, `nudge:mute:<트리거>`.
- 예전 버전이 올린 `nudge:chicken` 버튼을 누르면 버튼을 끄고 만료 안내를 띄운다.

## 결과

- 음식 얘기와 시간 얘기가 같은 투표로 이어진다. 1차 성공 기준도 "음식 얘기에서 실제로 시간 투표가 올라간다"로 바꾼다.
- 2차에 판 결과를 기록할 때 `matches(kind='quick')`를 쓴다.
