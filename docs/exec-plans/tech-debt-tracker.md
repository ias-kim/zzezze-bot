# 기술 부채

알면서 미뤄둔 것만 적는다. 해결하면 줄을 지우고 커밋 메시지에 남긴다.

| 항목 | 이유 | 갚을 시점 |
|---|---|---|
| `voice/lines.go` 대사는 Claude가 쓴 초안 | 방 말투는 원정 멤버가 제일 잘 안다 | 1차 배포 전 |
| 주사위 커스텀 이모지 미등록 (텍스트 ⚀~⚅로 대체 중) | 서버에 이모지 업로드가 필요 | 2차 (야추 화면) |
| `go.mod`의 go 버전 상향 필요 | modernc/sqlite는 1.25 이상 필요 (ADR 0002) | 2차, store 도입 시 |
| voice: 상수만 선언하고 `keys` 목록과 `lines` 표 **둘 다** 빠뜨린 키는 못 잡음 | Go에서 선언된 상수를 런타임에 나열할 방법이 없음. 쓰이지 않는 상수는 리뷰로 잡음 | 문제가 실제로 생기면 `go/ast` 기반 검사 추가 |
| `store/` PR의 reviewer 필수 규칙(ADR 0005)을 기계가 강제하지 않음 | 혼자 하는 프로젝트라 CODEOWNERS 효과가 없음 | 2차 시작 시 PR 템플릿 체크박스 추가 |
| 에이전트 동기화 검사는 지시문 **본문**만 비교함 (`.claude` frontmatter의 tools/model은 Codex 쪽에 대응 필드가 없음) | 두 도구의 설정 형식이 다름 | 필요해지면 |
| 로컬 Go(1.26)와 CI Go(`go.mod` 기준)가 다름 | 로컬 통과가 CI 통과를 보장하지 않음. CI가 기준 | 2차에서 go.mod 올릴 때 함께 정리 |
