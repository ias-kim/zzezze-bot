# ADR 0002: discordgo v0.29 업그레이드 (디스코드 기본 투표 사용)

## 상태

승인됨 (2026-09-23)

## 맥락

2번방에서 "몇시?"가 나오면 약속 시간을 모아야 한다. 처음 설계는 버튼 슬롯("다음 정각부터 4개")을 직접 만들어 집계하는 방식이었는데, 오후에 누르면 저녁 약속 시간이 빠지는 버그가 있었다. 디스코드 기본 투표는 복수 선택을 지원하고 선택지별 표 수를 보여주므로 겹치는 시간 집계를 대신해 준다.

`discordgo v0.28.1`에는 Poll 타입이 없다. `v0.29.0`부터 `MessageSend.Poll`, `Poll{AllowMultiselect, Duration}`을 지원한다(모듈 소스 `structs.go`, `message.go`에서 확인).

같은 시기에 확인한 사실: `modernc.org/sqlite v1.59.0`은 `go 1.25.0` 이상을 요구한다. arm64 크로스 빌드(`CGO_ENABLED=0`)는 통과했다.

## 결정

- discordgo를 v0.29.0으로 올리고, 시간 투표는 봇이 기본 투표(복수 선택, 3시간)를 게시하는 방식으로 만든다.
- SQLite를 도입하는 2차 배포에서 `go.mod`의 go 버전을 1.25로 올린다. CI는 `go.mod`에서 버전을 읽으므로 따로 맞출 필요가 없다.

## 결과

- 시간 집계 코드를 직접 쓰지 않아도 된다.
- Poll의 `Duration` 단위는 시간(hour)이다. 결과를 봇이 다시 읽을 필요는 없다.
- 1차 배포는 Go 1.23 그대로 가능하다.
