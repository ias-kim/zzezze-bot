# ADR 0005: store/ 변경에만 의미 게이트(reviewer) 필수

## 상태

승인됨 (2026-10-15). [ADR 0001](0001-harness.md)의 "의미 게이트는 필수로 강제하지 않는다"를 `store/`에 한해 뒤집는다.

## 맥락

ADR 0001을 쓸 때는 DB가 없어서 위험 영역이 없었다. 2차에서 SQLite 가상 포인트 원장(`store/`)이 생긴다. 현실 돈은 아니지만, 정산이 틀리면 친구들 사이의 신뢰가 깨지는 데이터다. 원장 규칙(append-only, `*sql.Tx`만 받기, 정산할 때 잔액 다시 검증)은 테스트로 일부만 고정할 수 있고 나머지는 의미 리뷰가 필요하다.

이 결정은 `docs/harness/profile.md`에 먼저 적혔고 ADR이 없었다. reviewer 서브에이전트의 감사(2026-10-15)에서 "조용히 뒤집힌 결정"으로 지적되어 이 문서로 기록한다.

## 결정

- `store/`를 바꾸는 PR은 머지 전에 `reviewer` 서브에이전트 리뷰를 받는다. 결과(차단/경고/통과)를 PR 본문에 붙인다.
- 그 밖의 PR에서 reviewer는 선택 사항이다.
- 지금은 이 규칙을 기계가 강제하지 않는다. 혼자 하는 프로젝트라 CODEOWNERS 같은 장치의 효과가 없다. 대신 PR 템플릿을 도입할 때 체크박스로 넣는다(기술 부채에 기록).

## 결과

- 비용: reviewer(sonnet) 1회는 약 7만 토큰이고, 2차 store 관련 PR 몇 건에만 든다.
- 1차 배포에는 영향이 없다.
