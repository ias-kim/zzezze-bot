# ADR 0006: 1차 배포는 치킨 판 대신 약속 카드

## 상태

승인됨 (2026-10-17, 사용자 결정). [ADR 0004](0004-chicken-first-rollout.md)의 1차 범위(치킨 판)를 대체한다. 2차·3차 범위(대결, 원장, 12라운드)는 0004 그대로다.

## 맥락

2번방 실제 대화(2026-10-14~15)를 모아 보니 "치킨"은 한 번도 나오지 않았다. 대신 약속을 잡는 말이 나왔다.

- 날짜와 초대: "일요일에 … 같이 피맥?", "30일에 뭐하세요", "30일에 … 함께하실래요"
- 술 약속은 `~맥`(피맥, 치맥 등)으로 말한다. 치킨은 그중 하나일 뿐이다.
- 약속은 오늘 저녁이 아니라 **며칠 뒤 날짜**로 잡힌다. 그래서 "오늘 18~23시" 시간 투표만으로는 쓸 수 없다.
- 장소는 후보 이름이 아니라 조건("근처", "지하철 있는 곳", "막차")으로 나온다.
- 기존 의도 패턴의 `ㄱ`는 게임 얘기("파트너 ㄱㄱ")에도 걸린다.

사용자는 주사위로 누가 쏠지 정하는 기능이 유치하다고 보고 빼기로 했다.

## 결정

- 1차 배포의 중심 기능을 **약속 카드**로 바꾼다. 신호(`~맥`, 날짜/시간 말, 제안 말) 중 두 가지가 함께 나오면 `[📅 약속 잡기]`를 제안한다.
- 카드에는 날짜, 참석 응답(`갈게/미정/패스`), 시간 투표 버튼을 둔다. 장소는 1차에서 다루지 않는다.
- 치킨 판(주사위로 결제자 정하기)은 만들지 않는다. 다시 꺼낼 일이 생기면 새 ADR로 정한다.
- 트리거 판정, 날짜 해석, 카드 상태 같은 규칙은 순수 패키지 `meetup/`에 둔다([ADR 0003](0003-pure-core-shared-session.md)). `yacht/`는 2차 대결부터 만든다.
- 시간 투표는 [ADR 0002](0002-discordgo-v029-poll.md)의 디스코드 기본 투표를 그대로 쓴다. 기준 날짜만 "오늘"에서 "카드의 날짜"로 바뀐다.

## 결과

- 아직 치킨 판 코드가 없어서 버리는 코드는 없다. `voice/`의 `Chicken*` 키는 5단계에서 약속 카드 키로 바꾼다.
- `session.Registry`에 판을 넣을 때 유저 역인덱스 등록을 선택할 수 있어야 한다. 한 사람이 약속 여러 개에 동시에 응답할 수 있기 때문이다(1:1 대결은 지금처럼 1인 1판).
- 실제로 약속을 잡는 대화는 DM으로 옮겨 가는 중이다. 봇이 방 안에서 약속을 잡게 만들지 못하면 쓰일 기회가 적다. 1차 배포 후 2주 동안 카드 사용 횟수를 보고 계속할지 정한다.
