# 하네스 프로파일

이 프로젝트에 하네스 엔지니어링을 적용할 때 참고하는 설정값. 값이 바뀌면 이 파일을 먼저 고친다.

| 항목 | 값 |
|---|---|
| 프로젝트 성격 | 개인 학습/사이드 프로젝트 (BM 증바람 서버용 디스코드 봇) |
| 스택 | Go(버전 원천은 `go.mod`. 2차에서 1.25로 올림, ADR 0002), discordgo v0.29, godotenv |
| DB | 1차: 없음. 2차: SQLite(`modernc.org/sqlite`)에 가상 포인트 원장 |
| API 형태 | 없음 (Discord 게이트웨이 이벤트 기반, REST/GraphQL 자체 노출 없음) |
| 코딩 에이전트 | Claude Code + Codex 둘 다 |
| CI | GitHub Actions, `make check` |
| 위험 영역 | `store/` (2차, 가상 포인트 원장. 현실 돈은 아니지만 잃으면 신뢰가 깨지는 데이터), `.env`의 `DISCORD_TOKEN` 유출 |
| 위험 경로 규칙 | `store/`를 바꾸는 PR은 `reviewer` 서브에이전트 리뷰(게이트 2)를 필수로 받는다 |
| 교차 모델 검증 | 미사용 (Lv.2에서는 불필요) |
| 목표 레벨 | Lv.2 |

## 레벨 산정 근거

개인 사이드 프로젝트 기본값(Lv.2)을 그대로 적용. 위험 영역이 없어 Lv.3의 의미 게이트(reviewer 서브에이전트)는 선택 사항으로 남겨두고, 필요해지면(예: 배포 자동화, 다른 서버로 확장) 올린다.

## 다음에 올릴 레벨

Lv.3: `make generate && git diff --exit-code` 스타일의 결정론적 산출물이 생기는 시점(예: 채널/기능 설정을 코드 대신 YAML SoT로 옮기고 코드를 생성) 또는 여러 사람이 기여하기 시작하면 `reviewer` 서브에이전트로 의미 게이트 추가.
