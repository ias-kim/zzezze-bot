# ADR 0007: 약속 트리거 판정에 AI(Claude Haiku 5.5)를 쓴다

## 상태

승인됨 (2026-10-17, 사용자 결정). [ADR 0006](0006-meetup-first-rollout.md)의 트리거 규칙("신호 세 가지 중 두 가지")을 이 문서가 대체한다.

## 맥락

약속을 제안하는 말투는 사람마다 다르다("30일에 뭐하세요", "같이 피맥?", "함께하실래요"). 정규식 신호 조합으로는 표현을 다 잡기 어렵고, 넓게 잡으면 게임 얘기("파트너 ㄱㄱ")에 오작동한다.

후보로 본 모델:

- **Claude Haiku 5.5**: 입력 $0.10, 출력 $0.50 (100만 토큰당). 한국어 지원. Go SDK(`anthropic-sdk-go`)가 있다.
- **TypeSafe AI Jev**: 판정 전용 모델. 입력 약 $0.042, 출력 무료라고 알려져 있다. 다만 2026-09-15 출시된 early access(대기 명단) 모델이다. 영어가 주력이라 한국어가 약하고 날짜 계산에 약하다고 알려져 있다. SDK는 JS와 Python뿐이다. 공식 사이트로는 확인하지 못했고 외부 정리 글로만 확인했다.

2번방 사용량(하루 메시지 약 300개)이면 두 모델 모두 월 $1이 안 된다. 그래서 비용은 고르는 기준이 되지 못한다.

## 결정

- 판정은 두 단계로 한다.
  1. **1차 필터**(순수 코드): 날짜·시간 말, `~맥`, 제안 말 중 하나라도 있는 판정 단위만 통과시킨다.
  2. **AI 판정**: 통과한 단위만 AI에 보내 "약속 제안인가"와 "날짜 표현 원문"(예: "일요일", "30일")을 받는다.
- 실제 날짜 계산은 AI가 아니라 `meetup/`의 순수 함수가 한다. 결과를 테스트로 고정할 수 있고, Jev처럼 날짜에 약한 모델로 바꿔도 영향이 없다.
- AI 호출은 `meetup`이 정의하는 판정 인터페이스 뒤에 둔다. 구현체는 `features/` 쪽에 두고 `main.go`가 주입한다. `make check`는 가짜 판정기만 쓰고 API를 부르지 않는다.
- 모델은 **Claude Haiku 5.5**(`claude-haiku-5-5`)로 시작한다. Jev 접근 권한이 생기면 같은 테스트 데이터로 정확도를 비교한 다음 다시 정한다.
- AI 호출이 실패하거나 3초 안에 답이 없으면 반응하지 않는다. 엉뚱하게 끼어드는 것보다 가만히 있는 게 낫다.
- AI에는 메시지 본문만 보낸다. 닉네임과 유저 ID는 보내지 않고, 멘션은 `@멤버`로 바꾼다.

## 결과

- 1차 필터를 통과한 2번방 대화가 외부 API(Anthropic)로 나간다. **배포 전에 원정 멤버들에게 알리고 동의를 받는다.**
- 트리거 테스트가 "정답 고정"에서 "정확도 측정"으로 바뀐다. `meetup/testdata/{hit,miss}.txt`는 그대로 쓴다. 1차 필터는 `make check`에서 hit을 하나도 놓치지 않는지 확인한다. AI 판정은 API 키가 필요한 별도 평가 명령(`make eval`, CI 밖)으로 잰다.
- API 키(`ANTHROPIC_API_KEY`)가 EC2 `.env`에 하나 더 생긴다.
