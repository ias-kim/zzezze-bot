# ADR 0006: 방 구분(1번방 mild / 2번방 full) 폐지

## 상태

승인됨 (2026-11-09, 사용자 결정)

## 맥락

설계 당시 1번방에는 비핵심 인원이 있어서 소음을 줄이려고 기능과 말투를 방마다 나눴다(1번방: nudge 없음, mild 톤). 이후 비핵심 인원이 모두 강퇴되어 서버에는 원정 멤버만 남았다.

## 결정

- 채널 ID 목록을 없앤다. 봇은 서버의 **모든 채널**에서 같은 기능(`AutoReply`, `Nudge`, `Yacht`)을 켜고 `full` 톤으로 말한다.
- `config.Lookup()` / `config.Enabled()` API는 그대로 둔다. 다시 방을 나눠야 하면 `config/channels.go`의 `Overrides`에 채널을 추가하면 된다.
- `voice`의 mild 대사는 지우지 않는다(Overrides로 다시 쓸 수 있고, 테스트가 두 톤을 모두 요구한다).
- 쿨다운과 `[🔕 오늘 그만]`은 계속 채널별로 적용한다.

## 결과

- 채널 ID를 코드에 하드코딩하지 않아도 된다. 새 채널을 만들어도 설정을 고칠 필요가 없다.
- exec-plan의 "1번방에서는 nudge가 반응하지 않는다" 완료 기준은 폐기한다.
